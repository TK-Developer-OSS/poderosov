PoderosoV ポータブル版 — Inspired by Poderosa 4.x


使い方
  PoderosoV.exe を実行してください。インストールは不要です。

設定の保存場所
  このフォルダの settings に、オプション・接続履歴・ホスト鍵などを保存します。
  フォルダごとコピーすれば、別の PC でも同じ設定で使えます。
  settings フォルダを削除すると、%APPDATA%\org.poderosov.terminal を使います。

必要なもの
  Microsoft Edge WebView2 ランタイム（Windows 10 / 11 には通常入っています）。

ショートカットファイル (.gts)
  Poderosa 4 の .gts を PoderosoV.exe と同じフォルダに置くと、
  ファイルメニューに一覧表示されます。

licenses フォルダに、同梱している第三者のソフトウェアのライセンスがあります。

PoderosoV は Poderosa 4.x に敬意を表して作られた独立した実装です。
Poderosa のコードは含まず、Poderosa Project とは関係ありません。
